# References I used

The Terraform configuration in this folder was written as a small educational example. I used the official documentation to check resource arguments:

- Terraform CLI 1.9: https://developer.hashicorp.com/terraform/cli
- AWS provider 5.70.0: https://registry.terraform.io/providers/hashicorp/aws/5.70.0/docs
- AWS EC2 user data: https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/user-data.html
- S3 public access block: https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-control-block-public-access.html
- EC2 Session Manager: https://docs.aws.amazon.com/systems-manager/latest/userguide/session-manager.html

This folder is not a fork of someone else's complete repository. If I reuse code from another project later, I need to keep its license and attribution.
