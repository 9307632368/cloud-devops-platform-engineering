# Version choices for this 2024 collection

I used versions which were available by the end of 2024 rather than pulling the newest tags into the examples.

| Item | Reference version | Why |
|---|---|---|
| Node.js | 20.18.1 | 2024 LTS release; zero npm dependencies |
| Prometheus | 2.55.1 | 2024 Prometheus 2.x release |
| Alertmanager | 0.28.0 | 2024 release |
| Grafana OSS | 11.3.0 | October 2024 release |
| Python | 3.11 or 3.12 | Built-in unittest + JSON log analysis |

Release references:

- https://nodejs.org/en/blog/release/v20.18.1
- https://github.com/prometheus/prometheus/blob/main/CHANGELOG.md
- https://github.com/prometheus/alertmanager/blob/main/CHANGELOG.md
- https://grafana.com/grafana/download/11.3.0?edition=oss

**Important:** These are historical learning pins, not recommended production security versions in 2026. Upgrade maintained systems to patched supported versions after checking breaking changes.
